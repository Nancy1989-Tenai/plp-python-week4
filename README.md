# PLP Python Week 4

## File Descriptions
- `welcome.py`: Contains a `welcome()` function that generates a personalized greeting message, which is called three times for different names.
- `toolbox.py`: Contains three utility functions: `double()` to multiply a number by 2, `is_pass()` to check if a score is 50 or above, and `greet()` to create a customizable greeting with an optional default parameter.

## Reflection
The `greet` function was the hardest to write because it required understanding how to use default parameter values in Python function definitions. Once I realized that setting `greeting="Hello"` directly in the parameters handles the default case automatically without needing an `if` statement, it became much simpler.
